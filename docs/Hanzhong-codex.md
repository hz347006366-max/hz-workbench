## 1. 我们在做什么

维护 HZ 个人工作台 Obsidian 插件，面向 Windows、Mac 和 iPhone。它把日记、时间记录、收支、月复盘、项目阶段甘特图、TickTick 只读任务集中到一个工作台。用户希望少问重复问题、小改动先跑定向测试、安装前统一验证。

本轮四项已确认需求：历史日期/时间补记、轮播拖动更顺滑、左侧济南天气中心、增加“棱镜玻璃·蓝金”主题。沿用既有工作台布局与项目功能，不重新设计整个产品。

## 3. 已实现的产品规则

### 每日日记与记录

- 右上角 `+` 打开“记录今日”菜单：今日照片、开始计时、结束当前计时、补记时间、随手记、记录收支、每日冥想、打开今日日记。
- 照片、随手记、冥想、收支可选历史日期与时间；默认现在，可点“现在”恢复。补记时间可选起止时间；开始/结束计时使用真实当前时间。
- 禁止未来时间、无效日历日期及不存在的本地时间；提交前校验，错误保留表单输入。
- 从某篇日记进入补记时绑定那篇文件及日期，不能误写今天。
- 保存后若开启自动打开，打开的是所选日期日记，使用新标签页并保留工作台。
- 缺失日记由 HZ 按模板创建，不依赖 Daily Notes 或任意 Templater 脚本。既有日记只打开，不重新套模板。
- 路径规则：`01 日记/YYYY年/M月/YYYY年-MM-DD-星期X.md`。模板允许的日期变量见 `src/daily-template-renderer.js`，禁止任意脚本执行。
- 照片冲突提供替换、追加、取消；保留首张图作为轮播封面。图片压缩失败会提示，不能假报成功。关闭弹窗后，尚未完成的图片解码不能继续写入。
- 照片和冥想记录的精确时间保存在受管理区的隐藏注释中，不混入轮播摘要。

### 日记轮播

- 卡片只显示日期和“每日冥想”一行摘要，不从旧摘要、标题或正文拼凑替代内容。
- 封面来自日记照片；支持年月筛选、手势连续拖动、惯性与吸附。
- 点侧卡先居中；点已居中的卡片在新标签打开对应日记。
- 保留自动轮播、悬停/后台暂停、减少动态效果与销毁清理。实现为拖动 RAF + 自动切换 CSS 过渡的轻量混合模式，不宣称所有运动均由同一 RAF 驱动。
- 未复制没有明确许可证的 `3D-card-acrylic` 源码，采用独立实现。

### 天气

- 左侧原智能体预留区改成天气；保留布局模块内部 ID `agent-panel` 以兼容用户保存的位置和大小，其显示名称为“天气”。
- 默认济南；手动搜索切换城市，保留最近 5 个城市，不索取定位权限，不需 API key。
- 当前天气、体感、风、紫外线、US AQI，以及未来 12 小时/7 天预报。详情默认折叠。
- Open-Meteo 公共网络接口，30 分钟缓存和刷新；手动刷新绕过缓存期限。断网有缓存则显示旧数据及时间，无缓存明确提示不可用，不伪造数据。
- 插件设置保存 `weatherLocation`、`weatherRecentLocations`、有界 `weatherCache`。无需用户给出 DeepSeek 或 TickTick 密钥。
- 移动布局顶端显示紧凑天气卡；减少动态或窄屏时停止天气背景动画。

### 配色与既有功能

- 新主题 ID：`prism-blue-gold`，界面名“棱镜玻璃·蓝金”。在右上角配色按钮或 HZ 设置中切换；照片、Logo 保持原色。
- 覆盖工作台、天气、项目和原生记录/项目弹窗，不将主题类写到全局 body。
- 省地勘局宿舍已按用户批准的新结构重建：1 个项目首页 + 15 个阶段文件。不是旧项目无损迁移；不要再次运行重建或迁移命令。
- 项目总览、阶段甘特图、点击阶段展开详细事项、新建项目向导沿用已实现版本。
- 月复盘：本月第一篇合规日记出现后自动创建 `YYYY年-MM-00-月复盘.md`，按名称排序排在当月日记前。兼容旧名 `YYYY年-MM月复盘.md`，不重复创建，不覆盖手写总结。

## 4. 必须保持的数据边界

- HZ 只读取 TickTickSync repository；不创建、修改、完成、删除 TickTick 任务，也不主动触发同步。
- “今日任务”的勾选框是本地“今日必完成”选择，最多 3 项；不是 TickTick 的完成开关。取消勾选只是取消必完成。
- 不扫描整个 Vault 从普通 Markdown 任务反推 TickTick 任务。没有缓存时应明确显示不可用。
- 保存布局要保留未知模块、旧布局备份和设备隔离；不要把 Windows 绝对路径写进可携带布局。
- 安装只复制 7 个发行文件：`main.js`、`manifest.json`、`styles.css`、`logo.png`、`THIRD_PARTY_NOTICES.md`、`LICENSE-prism-glass.txt`、`NOTICE-prism-glass.txt`。
- 绝不覆盖 live `data.json`，绝不把 DeepSeek、Copilot、TickTickSync、Remotely Save 的密钥配置打进接力包。
