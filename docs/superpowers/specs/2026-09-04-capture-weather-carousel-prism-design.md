# HZ 工作台补记、天气、轮播与棱镜玻璃设计规格

日期：2026-09-04  
状态：用户已逐节确认，待实施计划

## 1. 目标与范围

本轮在不破坏现有日记、项目、TickTick 展示和自由布局的前提下，新增四项能力：

1. “记录今日”支持为过去日期和具体时间补记。
2. 日记 3D 轮播改为更顺滑的惯性与吸附运动。
3. 左侧预留竖栏改为天气中心，默认城市为济南。
4. 新增“棱镜玻璃·蓝金”整套工作台主题。

四项能力必须模块化实现、独立失败、独立测试，最终统一安装和验收。

## 2. 补记日期与时间

### 2.1 交互

- “记录今日”弹窗顶部提供统一的日期与时间选择器，默认当前本地日期和时间。
- 时间精度为小时和分钟，允许直接输入，并提供“现在”快捷按钮。
- 允许选择今天或过去日期，不允许选择未来日期。
- 目标日期和时间应用于：今日照片、随手记、记录收支、每日冥想和补记时间。
- “开始计时”和“结束当前计时”始终使用真实当前时间；历史工作时间只能通过“补记时间”录入。

### 2.2 目标日记

- 记录写入用户所选日期对应的日记，而不是系统当天日记。
- 目标日记不存在时，使用插件设置中的日记模板路径创建；默认路径为 `07 模板/每日模板.md`。
- 新文件路径、文件名、frontmatter 和月复盘联动继续复用现有日记创建规则。
- 日记创建成功后才写入记录；失败时保留弹窗字段和所选时间，不留下半成品。

### 2.3 写入规则

- 随手记、收支、每日冥想和补记时间均使用所选时间作为记录时间与排序依据。
- 今日照片写入所选日期的照片区，并保留所选时间作为可解析元数据或说明。
- 若目标日期已有照片，提交前让用户二选一：替换原照片，或保留原照片并新增。
- 新旧模板均由现有标记与标题兼容层处理，不在界面中显示管理注释。

## 3. 左侧天气中心

### 3.1 布局

- 桌面端使用现有左侧预留竖栏，不再显示智能体占位内容。
- iPhone / 窄屏端将天气卡移动到工作台顶部。
- 移动端默认仅显示当前天气；点击后展开小时与七日预报。
- 天气模块失败不得阻断工作台其他模块渲染。

### 3.2 地址

- 默认地址为“中国山东省济南市”。
- 不请求设备定位权限。
- 点击城市名称打开搜索，结果必须显示足以区分重名地点的行政区信息。
- 选择后保存经纬度、时区、规范城市名和显示名。
- 保存最近使用的地址，允许快速切换；第一版最多保留 5 个最近地址。

### 3.3 数据与刷新

- 天气与地理编码使用 Open-Meteo 官方 API，不需要用户输入 API Key。
- 展示当前温度、天气状态、体感温度、今日最高/最低温、未来 12 小时温度与降水概率、未来 7 天、空气质量、风速和紫外线。
- 温度使用摄氏度，风速使用公里/小时，时间使用所选地点时区。
- 打开工作台时，缓存超过 30 分钟才请求更新；工作台持续打开时每 30 分钟刷新。
- 手动刷新绕过 30 分钟 TTL，但同一实例中应防止并发重复请求。
- 成功响应写入插件本地缓存。断网或接口错误时显示最近缓存和缓存时间，并标注“离线数据”。
- 没有缓存时显示独立错误卡与重试按钮，不显示伪造天气。
- 按 Open-Meteo 的许可与署名要求在详情区提供数据来源。

### 3.4 视觉

- 采用类似 Apple 天气的信息层级，不复制 Apple 图形资产或品牌标识。
- 晴天使用缓慢光晕，阴天使用云层渐变，雨天使用轻量细雨纹理。
- 动效只使用受控 CSS/DOM 图层，不使用视频、大型 Canvas 粒子或持续高频网络请求。
- iPhone、低性能模式或“减少动态效果”开启时使用静态背景。

## 4. 日记 3D 轮播

### 4.1 边界

- 保留现有日记索引、年月筛选、图片加载/填充、日期与每日冥想摘要，以及在新标签页打开日记的逻辑。
- 仅替换运动与交互控制层，不让轮播重新拥有全页渲染职责。
- `3D-card-acrylic` 仅作为交互和参数参考。由于仓库未提供明确许可证，不复制其源码、样式或资源。

### 4.2 运动模型

- 使用单一 `requestAnimationFrame` 循环驱动位置、速度、阻尼和吸附。
- 自动轮播从静止柔和加速，靠近下一张时减速并吸附到稳定槽位。
- 鼠标和触摸拖动直接控制连续位置；松开后按受限速度产生轻微惯性，再吸附到最近卡片。
- 速度、阻尼和吸附阈值集中为可测试配置，不散落在 DOM 事件中。
- 切换数据集或月份时保持当前日记路径；路径不存在才回退到第一项。

### 4.3 点击与暂停

- 点击侧边卡片只将其平滑居中，不打开文件。
- 点击已经居中的卡片，在新标签页打开对应日记并保留工作台。
- 必须区分点击与拖动，超过移动阈值的手势不得误开日记。
- 悬停、触摸、拖动、自由布局编辑、年月切换和视图不可见时暂停自动轮播。
- 所有暂停原因使用现有 reason-set 语义叠加，只有全部原因解除才恢复。
- `prefers-reduced-motion` 或插件“减少动态效果”开启时禁用惯性、呼吸与复杂景深，使用短淡入或直接切换。

### 4.4 清晰度与性能

- 图片/材质层可以使用景深、透明度和明暗变化。
- 日期与每日冥想文字层独立，禁止继承 `filter`、`blur` 或 `backdrop-filter`。
- 后台标签页停止动画循环；销毁视图必须取消 RAF、计时器和事件监听。
- 移动端轮播手势区使用 `touch-action: pan-y`：轮播只接管横向拖动，纵向手势继续滚动页面。

## 5. 棱镜玻璃·蓝金主题

### 5.1 主题来源与许可

- 新增独立主题 ID `prism-blue-gold`，显示名“棱镜玻璃·蓝金”。
- 采用 Prism Glass 的 US-11 蓝金体系：`#0A1335`、`#163B7A`、`#4B70BE`、`#C89A55`、`#F2D79E`。
- Prism Glass 为 Apache-2.0；发行包保留所需 LICENSE/NOTICE 署名，但不复制作者品牌素材。

### 5.2 作用范围

- 主题覆盖工作台背景、统计卡、天气中心、日记轮播、项目总览、项目驾驶舱、甘特图、弹窗和按钮。
- 通过语义变量表达画布、环境光、玻璃表面、边框、正文、弱化文字、强调色、高光、警告、成功和图表色。
- 业务组件只能消费语义变量，不直接绑定 `US-11` 或五个原始色值。
- 日记照片、天气图标、Logo 和内容图片不应用灰度、色相、模糊或整体透明滤镜。
- 主题通过右上角调色按钮循环切换，也可在插件设置中直接选择；现有主题全部保留。

### 5.3 降级

- 常规模式允许轻微背景环境光、玻璃染色与静态边缘高光。
- 低性能/减少动态效果模式关闭流动高光，减少 backdrop-filter 层级并保持信息层次。
- 不支持 `backdrop-filter` 时必须得到可读的纯色半透明表面。

## 6. 模块边界与数据流

- 补记由日期时间模型、日记定位/创建服务和各记录写入器组成；Modal 只收集输入和展示错误。
- 天气由地址仓库、Open-Meteo 客户端、缓存策略和天气视图组成；视图不直接请求网络。
- 轮播由纯运动模型和 DOM 控制器组成；运动模型不读取 Vault。
- 主题由语义 token 和主题选择器组成；业务逻辑不感知具体配色。
- 所有设置与缓存写入现有插件 `data.json`；不在日记或项目正文中存天气缓存。

## 7. 错误处理与隐私

- 城市搜索只传输用户主动输入的地名；不读取 GPS、IP 定位或精确住址。
- 网络超时、限流、无结果、畸形响应分别转换为中文可理解错误。
- 天气模块应设置请求超时并忽略过期响应，防止旧城市结果覆盖新城市。
- 记录写入必须串行化同一目标文件，避免快速重复提交造成内容覆盖。
- 轮播资源加载失败仅影响对应卡片，保留日期和摘要占位。

## 8. 验收标准

### 8.1 自动测试

- 补记：过去日期、跨月、自动建日记、未来日期拦截、照片替换/新增、错误保留输入、并发写入。
- 天气：济南默认地址、重名地址选择、缓存 TTL、手动刷新、并发去重、离线缓存、无缓存错误、时区和单位。
- 轮播：惯性、阻尼、吸附、手势阈值、两段点击、暂停 reason、隐藏视图、销毁清理、减少动态效果。
- 主题：主题注册、语义 token 覆盖、现有主题不回归、图片无滤镜、降级样式。
- 执行完整 `scripts/run_all_checks.py`，development 与 install 发行文件哈希一致。

### 8.2 真机与视觉验收

- Windows Obsidian：完整交互、重载、错误降级、性能和主题切换。
- iPhone 宽度模拟：天气折叠、触控轮播、记录弹窗、44px 最小触控目标、无横向溢出。
- 最终集中生成/展示整体效果，不在各小步骤反复要求用户检查。

## 9. 实施顺序

1. 补记日期与时间。
2. 天气客户端、缓存与桌面/移动视图。
3. 轮播纯运动模型与控制器替换。
4. 棱镜玻璃·蓝金主题及许可证文件。
5. 全量回归、版本更新、安装、Windows 与移动端验收。
6. 更新 `09 知识库/Hanzhong-codex.md` 和接力包。

## 10. 明确不做

- 不接入 Apple WeatherKit，不申请 Apple Developer 凭据。
- 不申请设备定位权限。
- 不复制无明确许可证的 3D Card Acrylic 源码。
- 不加入完整 16 套 Prism Glass Palette；本轮只做 US-11 蓝金主题。
- 不把天气数据写入日记。
- 不恢复已取消的智能体占位面板。
