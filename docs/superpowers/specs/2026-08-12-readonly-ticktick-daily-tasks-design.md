# TickTick 只读日程与日记任务面板设计

## 目标

以 TickTick 为唯一任务数据源。HZ 个人工作台和每日日记只读取 TickTickSync 已缓存到本地的数据，不在 Obsidian 中新增、修改、完成或删除 TickTick 任务。

工作台提供一个独立的本地“今日必完成”选择层；它只记录当天选中的 TickTick 任务 ID，不改变 TickTick 任务本身。

## 数据边界

### TickTick 任务源

- 插件通过独立的只读适配器读取 TickTickSync 运行时的本地任务仓库。
- 适配器不得调用 TickTickSync 同步命令、REST 写接口或 Markdown 修改接口。
- 适配器不得修改 TickTickSync 的数据库、检查点、项目、标签或登录设置。
- TickTickSync 未启用、尚未登录或本地缓存不可用时，面板显示可理解的空状态，不回退为扫描整个 Vault 中的普通复选框。
- “全部任务”指 TickTickSync 本地任务仓库当前可读取的全部 TickTick 任务；云端变化由 TickTickSync 自己更新缓存，HZ 插件仅刷新展示。

### 只读交互

- 任务复选框只反映完成状态，设置 `disabled` 并从可编辑交互中移除。
- 任务标题使用普通文本，不可点击，不打开 TickTick、浏览器或本地文件。
- HZ 插件不提供任务新增输入框。
- 工作台不再触发 `tickticksync:tts-sync`。

### 今日必完成本地选择

- “今日必完成”是“今日任务”的重点子集，不是新的任务数据。
- 每条今日任务提供“设为必完成 / 取消必完成”开关。
- 每个自然日最多保存 3 个 TickTick 任务 ID。
- 选择记录存入 HZ 插件自己的 `data.json`，按本地日期键 `YYYY-MM-DD` 分组。
- TickTick 中任务完成后仍保留在当日“今日必完成”，并显示只读完成状态。
- 已从 TickTickSync 缓存消失的任务不渲染；其无效 ID 在下次保存该日期选择时清理。

## 任务日期规则

- 工作台“今日任务”显示电脑当天到期的全部 TickTick 任务，包括已完成任务。
- 工作台“今日必完成”显示当天本地选中的任务，包括已完成任务。
- 日记“今日任务”按该篇日记自身日期显示全部任务，包括已完成任务。
- 日记“明日行动”按该篇日记日期的下一自然日显示未完成任务。
- 日期比较使用本地日历日，不能用 UTC 截断导致跨日。
- 没有到期日期的任务不进入今日或明日面板。

## 日记动态代码块

插件注册 `hz-tasks` Markdown 代码块处理器。代码块只声明查询，不保存任务正文。

今日任务：

````markdown
```hz-tasks
scope: today
includeCompleted: true
```
````

明日行动：

````markdown
```hz-tasks
scope: tomorrow
includeCompleted: false
```
````

处理器通过 `ctx.sourcePath` 定位当前日记，按以下顺序解析基准日期：

1. 日记 frontmatter 的 `date`；
2. 现有中文日记文件名；
3. 现有日记日期解析器的文件夹与文件元数据回退。

无法解析日记日期时显示“无法识别日记日期”，不使用电脑当天静默替代。

## 每日模板调整

`F:/Obsidian/07 模板/每日模板.md` 的“今日整理”保持以下顺序：

```text
今日整理
├─ 今日摘要
├─ 重要决定与分流
├─ 今日任务
└─ 明日行动
```

模板中的静态 `- [ ] #ticktick` 行删除，替换为两个 `hz-tasks` 动态代码块。模板之外的照片、时间记录、随手记和收支内容保持不变。

## 轮播打开日记

- 整张轮播卡片均可激活，包括图片、标题和空白区域。
- 鼠标单击、键盘 Enter 和 Space 都在新标签页打开该卡片当前绑定的日记。
- 使用 `workspace.getLeaf('tab').openFile(journal.file)`，工作台标签保持打开。
- 拖动轮播后产生的合成 click 仍须被抑制，避免误打开。
- 回收复用后的卡片必须读取最新绑定的日记，不能打开旧卡片路径。

## 工作台界面变化

### 今日任务

- 显示当天全部 TickTick 任务。
- 显示只读复选框、纯净标题和“设为必完成 / 取消必完成”按钮。
- 不再点击整行打开源文件。
- 达到 3 项后，其他未选择任务的“设为必完成”按钮禁用，并给出“最多 3 项”的说明。

### 今日必完成

- 删除输入框和提交按钮。
- 只显示当日选中的最多 3 项。
- 每项显示只读完成状态和“取消必完成”按钮。
- 空状态提示用户从“今日任务”中选择。

## 刷新与生命周期

- 工作台首次打开、TickTickSync 完成同步或 Obsidian 布局恢复后刷新只读任务数据。
- Markdown 动态面板在渲染时读取快照；TickTickSync 缓存变化后，通过 Markdown 视图刷新事件更新当前可见面板。
- 所有 TickTickSync 事件监听必须在插件卸载时注销。
- 若 TickTickSync 没有稳定的同步完成事件，使用有界、去抖的 Vault/工作区刷新信号，不使用持续轮询。

## 错误与安全处理

- 读取适配器异常时记录一次可诊断错误，并在界面显示“TickTick 数据暂不可用”。
- 不弹出删除确认，不自动确认 TickTickSync 的任何删除请求。
- 不启用 Full Vault Sync，不批量添加 `#ticktick`。
- 本功能不更改现有 TickTickSync 隔离配置；若缓存范围不足，应先报告配置差异，不自动扩大同步范围。

## 测试与验收

- 单元测试覆盖本地日期比较、今天全部/明天未完成过滤、只读标题和完成状态。
- 单元测试覆盖每日最多 3 项、切换取消、跨日期隔离和失效 ID 清理。
- Markdown 处理器测试覆盖 frontmatter、中文文件名、历史日记、空状态和不可识别日期。
- 模板测试精确断言“今日任务”位于“明日行动”上方且没有静态 `#ticktick` 任务行。
- 工作台测试断言无任务输入框、复选框不可用、标题没有 click 导航、选择按钮只改 HZ 设置。
- 轮播测试断言整卡鼠标与键盘在新标签页打开正确日记。
- 全量测试、构建、安装产物哈希与 Windows Obsidian 实机验收全部通过后交付。
