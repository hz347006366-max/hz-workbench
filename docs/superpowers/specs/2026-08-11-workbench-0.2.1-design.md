# HZ 个人工作台 v0.2.1 设计规格

日期：2026-08-11
状态：已确认，待实施

## 目标

在不改变用户已保存模块位置和模块自身缩放比例的前提下，修复桌面工作台的视口放大、日记日期索引、轮播筛选、日记跳转和深色主题问题，并为自由布局增加一个始终可见、行为明确的锁定开关。

## 设计原则

- 保留现有自由布局数据，不重排、不重置用户布局。
- 视口变化只影响整张画布的显示比例，不改写单个模块的保存尺寸。
- 日记年月以日记自身日期为准，文件系统时间仅作为最后回退。
- 工作台和日记各自保留在独立标签页。
- 深色主题只改变界面色彩，不改变用户图片。
- 自由布局必须显式解锁，重新锁定即保存。

## 1. 自适应视口

桌面画布仍以 1440px 为设计基准。视口缩放规则改为：

- 可用宽度小于基准宽度时，按宽度等比例缩小。
- 最小显示比例维持现有 68%，低于该宽度时允许视口滚动。
- 可用宽度大于基准宽度时，显示比例最多为 100%，不再继续放大。
- 画布不足以铺满视口时水平居中，多出的空间表现为背景留白。
- Obsidian 左右侧边栏展开、收起或窗口尺寸变化时立即重新计算。
- 不修改布局文件中任何模块的 x、y 或 scale。

## 2. 日记日期识别与年月筛选

### 日期解析优先级

1. Frontmatter 的 date、day 或 created 字段。
2. 文件名中的 YYYY-MM-DD。
3. 文件名中的 YYYY年-MM-DD，包括 YYYY年-MM-DD-星期X。
4. 路径中的年份、月份目录，例如 2024年/12月/，与文件名中的日组合。
5. 文件创建时间，仅作为无法从内容和路径识别日期时的回退。

解析结果必须经过真实日历日期校验。无效日期不得生成错误的年月选项。

### 筛选交互

- 年份下拉框显示所有存在日记的年份，按新到旧排列。
- 月份下拉框只显示所选年份中存在日记的月份，按新到旧排列。
- 用户切换年份后，默认进入该年份最新的有效月份。
- 用户切换月份后，立即重建当月轮播内容。
- 选项显示为“2024年”“12月”，内部仍使用规范值 2024、12。
- 数据刷新时尽可能保留当前日记及其年月选择。
- 当前月份没有可展示内容时显示空状态，不误跳到文件导入月份。

## 3. 轮播卡片打开日记

- 单击任意可见轮播卡片，在新的 Obsidian 标签页中打开该卡片绑定的日记。
- 原工作台标签页保持打开，布局和当前筛选状态不被替换。
- 新标签页成为活动标签页，便于立即阅读或编辑日记。
- 拖动轮播后产生的合成点击仍需被抑制，普通点击不受影响。
- 键盘 Enter 与 Space 采用相同的新标签页打开行为。
- 非可见、正在回收或无日记数据的卡片不可触发打开。

## 4. “墨影黑白”调整为深色主题

保留主题名称“墨影黑白”，但视觉方向调整为类似 Codex 的中性深色界面：

- 页面背景使用接近黑色的中性深灰。
- 卡片使用分层深灰，依靠明度和细边框区分层级。
- 主文字为柔和灰白，次要文字降低对比度。
- 交互焦点和选中状态使用低饱和冷色强调，避免纯白高亮刺眼。
- 删除轮播封面的灰度滤镜；本地和网络封面均保持原始颜色。
- 不对 Logo、热力图、图片或其他用户内容施加全局滤镜。
- 保持现有主题切换方式和主题键值，避免旧设置失效。

## 5. 自由布局锁定开关

### 位置与状态

- 在工作台视口右上角增加悬浮小锁按钮。
- 按钮属于视口级界面，不属于任何可移动模块，因此不会随自由布局移动或缩放。
- 默认及加载完成后为锁定状态。
- 锁定图标表示当前布局已锁定；开锁图标表示当前正在编辑。
- 提供中文悬浮提示、无障碍名称和清晰的焦点样式。

### 交互

- 点击锁定图标：切换为开锁状态并进入自由布局编辑。
- 开锁期间：允许选择、拖动和等比例缩放模块。
- 再次点击开锁图标：校验布局、保存布局、退出编辑并恢复锁定状态。
- 存在重叠冲突时不得静默保存；保留编辑状态并显示现有冲突反馈。
- 保存失败时保留编辑状态并显示错误提示，避免用户误以为已保存。
- “撤销”和“恢复默认布局”继续在编辑工具栏中提供。
- Escape 取消本次未保存调整并恢复锁定状态。
- 移除长按模块进入编辑的入口，避免普通点击、筛选和卡片跳转被误判为布局操作。

## 6. 状态与生命周期

- 工作台刷新或重新渲染时，锁定按钮恢复为锁定状态。
- 数据自动刷新在编辑期间继续排队，锁定并保存后再执行。
- 关闭工作台、切换活动叶片或窗口失焦时中断正在进行的拖动/缩放。
- 离开编辑不产生未处理的指针捕获、定时器或事件监听器。
- 视口自适应与模块编辑使用同一画布坐标换算，缩放后拖动距离保持准确。

## 7. 测试与验收

实施采用测试先行，至少覆盖：

- 视口宽于 1440px 时画布比例不超过 1，且舞台居中。
- 视口变窄、侧边栏开合和 ResizeObserver 触发时正确重新计算。
- 2024年-12-01-星期日.md 被归入 2024 年 12 月，而不是文件创建月份。
- Frontmatter、标准文件名、中文文件名、目录回退和无效日期的优先级。
- 年份和月份切换后卡片池只包含目标月份日记。
- 卡片单击与键盘激活请求新的标签页，工作台叶片不被替换。
- 拖动后的合成点击仍被抑制。
- “墨影黑白”不存在封面灰度或全局图片滤镜。
- 锁定按钮进入编辑、保存退出、冲突拒绝保存、保存失败和 Escape 取消。
- 原有布局文件可无迁移加载，模块坐标和缩放不变。
- 全部自动测试、语法检查、构建和发布包检查通过。

## 8. 发布

- 插件版本更新为 0.2.1。
- 构建产物保持精简，仅安装运行所需文件。
- 安装前备份当前 F:\Obsidian\.obsidian\plugins\hz-workbench。
- 安装到当前 Obsidian 后重新加载插件并进行 Windows 实机验收：
  1. 展开和收起 Obsidian 左侧栏，工作台不放大。
  2. 选择 2024 年及不同月份，内容与文件日期一致。
  3. 点击轮播图片，新标签页打开日记且工作台仍存在。
  4. 切换“墨影黑白”，界面变深而图片保持彩色。
  5. 开锁编辑模块，关锁保存，重载后布局保持。
