# 每日日记编辑提示与技术标记隐藏设计

## 背景

HZ 个人工作台 0.3.0 的每日模板使用普通 Markdown 标题与成对 `hz:*` HTML 注释。该结构便于“记录今日”稳定写入照片、时间、随手记和收支，但电脑端直接编辑时缺少填写引导，源码模式与实时预览中还会看到技术标记，写作体验不够直观。

本设计在不改变 Markdown 数据、不删除插件定位标记的前提下，为日记编辑器增加临时填写提示，并在默认状态下隐藏技术标记。用户形成习惯后可以关闭提示。

## 目标

- 让电脑端日记的空栏目明确显示“可以写什么、应该如何添加”。
- 让用户点击灰色提示后立即进入对应记录表单或正确的文字输入位置。
- 在源码模式和实时预览模式中默认隐藏合法的 `hz:*` 技术标记。
- 保留现有模板、移动端“记录今日”、TickTick 只读任务和同步方式。
- 通过设置随时关闭填写提示或重新显示技术标记。

## 非目标

- 不把日记改造成独立表单或第二套编辑器。
- 不删除或迁移模板中的 `hz:*` 标记。
- 不修改历史日记正文。
- 不改变“记录今日”的写入格式与 marker 协议。
- 不修改 TickTickSync、任务数据、附件、工作台布局或轮播逻辑。
- 不批量迁移旧日记。

## 适用范围

编辑辅助只对 frontmatter 中 `type: 日记` 的 Markdown 生效。项目、知识库、模板说明和其他普通笔记不显示提示，也不隐藏其中偶然出现的相似文本。

源码模式和实时预览模式必须保持一致。移动端快捷记录协议和表单不受影响；若移动端打开原生日记编辑器，同一编辑辅助可按设置正常工作。

## 用户体验

### 技术标记

- 完整、合法、可配对的 `<!-- hz:...:start -->` 与 `<!-- hz:...:end -->` 默认在编辑器中隐藏。
- 隐藏时同时收起仅由标记造成的视觉空行，但不改变文档字符与行号映射。
- 阅读模式继续遵循 Markdown 对 HTML 注释的原生隐藏行为。
- 标记缺失、重复、顺序错误或只有一半时不隐藏，以便用户和开发者发现结构问题。
- 设置中开启“显示日记技术标记”后，所有标记恢复原始可见状态。

### 灰色占位提示

提示只存在于编辑器装饰层，不写入 Markdown，不参与同步和搜索。

| 栏目 | 空白时显示的提示 |
| --- | --- |
| 今日照片 | 通过“记录今日”添加今天最有意义的一张照片 |
| 时间流水 | 通过“记录今日”开始计时、结束计时或补记时间 |
| 随手记 | 此刻有什么值得记下的想法？ |
| 收支流水 | 通过“记录今日”添加今天的收入或支出 |
| 今日摘要 | 今天最值得记住的事情是什么？ |
| 重要决定与分流 | 今天做了什么决定？后续应该放到哪里？ |

“今日任务”和“明日行动”不显示输入提示，因为这两个区域由 `hz-tasks` 从 TickTickSync 只读展示。

### 出现与消失规则

- 对 marker 管理栏目，忽略成对 marker 与纯空白后没有正文、图片或插件记录时，显示提示。
- 对手写栏目，以当前标题到下一个同级或更高级标题之间的实际 Markdown 内容判断是否为空。
- 用户输入文字、插入图片或插件写入记录后，提示立即消失。
- 用户删除栏目中的全部实际内容，或撤销到空状态后，提示重新出现。
- 提示开关关闭后不显示任何占位提示，但不影响技术标记隐藏开关。

### 点击与键盘交互

- 提示可以用鼠标点击，也可以通过键盘聚焦后激活。
- 今日照片提示直接打开“记录今日 → 今日照片”表单。
- 时间流水提示打开“记录今日”菜单，让用户选择开始计时、结束当前计时或补记时间。
- 收支流水提示直接打开“记录今日 → 记录收支”表单。
- 随手记、今日摘要和重要决定与分流提示激活后重新解析当前文档，再将光标放到标题后的第一个安全空白行。
- 随手记的光标位于标题与 `hz:quick-notes:start` 之间的普通空白行；插件通过“记录今日”写入的随手记仍保存在 marker 内，两种内容都计入“该栏目是否为空”的判断。
- 定位失败时不写入、不移动到猜测位置，也不修改笔记。
- 文字输入、粘贴、撤销、重做和保存继续完全由 Obsidian 编辑器处理。

## 样式

- 提示字号略小于正文，使用 Obsidian 的弱化文字语义变量。
- 不使用边框、卡片或大面积背景，避免形成额外表单感。
- 鼠标悬停时轻微增强对比度并显示可点击光标。
- 键盘聚焦时使用清晰的 `focus-visible` 轮廓。
- 深色、浅色、墨影黑白及其他 Obsidian 主题均使用主题变量，不写死黑白或品牌颜色。
- 隐藏标记与提示不得改变标题间距、编辑器宽度或正文布局。

## 设置

HZ 个人工作台设置新增两个独立布尔项：

1. `显示日记填写提示`
   - 默认：开启。
   - 关闭后所有灰色提示立即消失。
   - 用于用户形成习惯后取消引导。
2. `显示日记技术标记`
   - 默认：关闭。
   - 开启后恢复 `hz:*` 注释原始可见状态，便于排错。

设置必须保存到现有 HZ 插件设置中，重启 Obsidian 后保持。切换设置只重新配置已打开的编辑器，不修改任何 Markdown。

## 架构

### 纯解析层

新增一个不依赖 Obsidian DOM 的日记编辑结构解析单元，职责为：

- 判断 frontmatter `type: 日记`；
- 找到精确标题及标题内容边界；
- 找到并校验成对 `hz:*` 标记；
- 判断六个目标栏目是否为空；
- 返回可隐藏标记范围，以及提示的位置、交互类型、记录动作或可编辑光标位置；
- 在结构异常时返回保守结果，不猜测修复。

该层接收当前文档文本并返回普通数据，便于用 Node 测试完整覆盖。

### 编辑器装饰层

使用 Obsidian 编辑器扩展将解析结果映射为：

- 技术标记隐藏装饰；
- 空栏目提示 widget；
- 文字提示的光标定位与记录工具提示的动作回调；
- 文档或设置变化后的增量重算。

装饰层不调用 Vault 写入，不保存业务数据，不扫描整个 Vault。一次更新只处理当前打开的文档。

### 插件设置与生命周期

- 插件加载时注册一个编辑器扩展实例。
- 设置变化时更新 extension state，使所有已打开日记即时刷新。
- 插件卸载时移除装饰与事件处理器。
- 现有“记录今日”写入导致编辑器文档更新后，沿用相同更新路径自动隐藏提示。

## 数据流

1. 用户打开或编辑一篇日记。
2. 编辑器扩展读取当前文档与 frontmatter 状态。
3. 纯解析层返回 marker、空栏目、提示位置、交互类型、记录动作或光标位置。
4. 装饰层按设置隐藏合法标记并显示空栏目提示。
5. 用户点击提示时，扩展对最新文档重新解析。
6. 若是照片、时间或收支提示，扩展调用 HZ 插件提供的记录动作回调；若是随手记、摘要或决定提示，编辑器把光标放到目标安全空白行。
7. 用户通过记录表单或 Obsidian 原生编辑器输入；文档事务触发重新计算，提示消失。

该流程没有额外的 Vault 写入，也不改变 Remotely Save、Obsidian Sync 或 iCloud 的工作方式。

## 异常与安全边界

- 非日记笔记直接返回空装饰集合。
- 缺少目标标题时跳过对应提示，不弹出干扰写作的错误。
- marker 非法时不隐藏该 marker，也不猜测其受控范围。
- 文档在点击与定位之间变化时，必须用最新状态重新计算。
- 无法确认光标位置时安全退出，不写入占位文字。
- 解析错误不得阻止用户继续编辑；最坏情况只是显示原始 Markdown。
- 不访问 TickTickSync 写接口，不执行同步命令，不扫描日记目录。

## 测试策略

### 纯逻辑测试

- 识别 `type: 日记`，排除其他笔记。
- 六个空栏目分别生成正确提示和位置。
- 文字、图片、列表及插件记录使提示消失。
- 删除内容或撤销到空状态后重新生成提示。
- 完整 marker 成对返回隐藏范围。
- 缺失、重复、交叉或逆序 marker 不隐藏。
- 手写栏目边界在下一个同级或更高级标题处停止。
- `hz-tasks` 区域不生成输入提示。

### 编辑器边界测试

- 源码模式和实时预览使用相同解析结果。
- 照片、时间与收支提示调用且只调用对应记录入口。
- 随手记、摘要与决定提示在重新解析后设置正确光标。
- 过期位置不会导致错误写入。
- 两个设置开关独立、即时且可持久化。
- 插件卸载后不残留装饰与监听器。
- CSS 使用 Obsidian 主题变量，并具备 hover 与 `focus-visible`。

### 回归与发布验证

- 现有每日模板、移动记录、TickTick 只读、轮播和布局测试继续通过。
- 完整语法检查和全量测试通过。
- 重新构建 development 产物。
- development 与 install 的 `main.js`、`styles.css` 逐字节一致。
- live 安装前完整备份 HZ 插件并核对 SHA-256。
- 安装只覆盖必要发布产物，不改 `data.json`、logo、日记、模板、TickTickSync 或布局。

## 实机验收

在实际 Obsidian 中使用一篇不含个人测试数据的受控副本或经授权的临时笔记验证：

1. 源码模式与实时预览都看不到合法技术标记。
2. 六个空栏目显示准确提示。
3. 点击照片、时间和收支提示分别打开照片表单、记录今日菜单和收支表单。
4. 点击随手记、摘要和决定提示后，光标位于对应栏目第一安全可编辑行。
5. 手动输入后提示消失，撤销清空后提示恢复。
6. “记录今日”写入照片、时间或收支后对应提示消失。
7. 两个设置开关即时生效，重载后保持。
8. 非日记笔记与两个 `hz-tasks` 区域不受影响。
9. 深色、浅色和墨影黑白主题下提示清晰但不抢正文视觉层级。

只有自动化验证、发布产物验证与上述实机路径均通过，才宣称功能完成并安装。
