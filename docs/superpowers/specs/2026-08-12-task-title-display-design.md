# 任务标题纯净显示设计

## 目标

工作台中的“今日必完成”和“今日任务”卡片只显示用户输入的任务文字，不显示 TickTickSync 为双向同步附加的英文标签、链接、ID、日期或优先级标记。

## 显示规则

例如源文件保存：

```markdown
- [ ] HZ工作台同步测试 #hzworkbench [link](https://ticktick.com/...) #ticktick %%[ticktick_id:: abc123]%% 📅 2026-08-12
```

卡片标题只显示：

```text
HZ工作台同步测试
```

显示清洗依次移除：

- `#hzworkbench` 与 `#ticktick`；
- Markdown 链接 `[link](...)`，不保留链接标签；
- TickTick 内联 ID `%%[ticktick_id:: ...]%%`；
- 到期日标记与日期；
- Tasks/TickTick 优先级符号；
- 清洗后多余的空白。

普通中文、英文、数字和用户自行输入的其他内容保持不变。若用户正文中本来包含英文，仍正常显示；“取消英文”仅指隐藏插件生成的英文同步元数据。

## 数据边界

- 仅改变工作台显示层。
- 不修改日记 Markdown 源文件。
- 不删除 TickTick 链接、ID、同步标签或日期。
- 不改变 TickTickSync 的双向同步逻辑和隔离标签设置。

## 实现与验证

- 在任务解析边界增加可独立测试的标题清洗函数，两个任务面板复用同一结果。
- 单元测试覆盖完整 TickTickSync 行、普通任务文字以及重复空白。
- 运行全量测试与构建，安装 `main.js` 后在 Obsidian 实机验证卡片标题。
