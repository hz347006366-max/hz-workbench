# HZ 个人工作台 v0.2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 v0.2.1，使桌面工作台不随宽视口放大，正确按真实年月筛选日记，在新标签页打开日记，提供显式自由布局锁，并将“墨影黑白”改为保留彩色图片的 Codex 风格深色主题。

**Architecture:** 保持 1440px 逻辑画布和每设备布局文件不变，只限制视图层显示比例。新增纯日期解析模块作为日记索引的单一日期入口；轮播控制器继续负责筛选与卡片池，WorkbenchView 只负责 Obsidian 导航。自由布局改为视口级锁按钮显式驱动 LayoutController，不再通过长按普通内容进入编辑。

**Tech Stack:** Obsidian Plugin API、CommonJS、原生 DOM/CSS、Node.js `node:test`、JSDOM、esbuild。

```js
function validDate(year, month, day) {
  const value = new Date(Number(year), Number(month) - 1, Number(day));
  if (value.getFullYear() !== Number(year)
    || value.getMonth() !== Number(month) - 1
    || value.getDate() !== Number(day)) return '';
  return year + '-' + month + '-' + day;
}

function dateIn(value) {
  const text = Array.isArray(value) ? value.join(' ') : String(value ?? '');
  const match = text.match(/(\d{4})(?:年-|-)(\d{1,2})-(\d{1,2})/);
  if (!match) return '';
  return validDate(match[1], match[2].padStart(2, '0'), match[3].padStart(2, '0'));
}

function folderDate(file) {
  const folder = String(file?.path || '').match(/(?:^|\/)(\d{4})年\/(\d{1,2})月\//);
  const day = String(file?.basename || '').match(/^(\d{1,2})(?:日|$)/);
  if (!folder || !day) return '';
  return validDate(folder[1], folder[2].padStart(2, '0'), day[1].padStart(2, '0'));
}

function ctimeDate(file) {
  const value = new Date(Number(file?.stat?.ctime));
  if (!Number.isFinite(value.getTime())) return '';
  return validDate(
    String(value.getFullYear()),
    String(value.getMonth() + 1).padStart(2, '0'),
    String(value.getDate()).padStart(2, '0'),
  );
}

function resolveJournalDate(file, frontmatter = {}) {
  for (const value of [frontmatter.date, frontmatter.day, frontmatter.created]) {
    const resolved = dateIn(value);
    if (resolved) return resolved;
  }
  return dateIn(file?.basename) || folderDate(file) || ctimeDate(file);
}

module.exports = { resolveJournalDate };
```

Frontmatter 数组先连接为字符串；月份和日期补齐两位；每个候选都调用 `validDate`。

```js
enterEdit(moduleId = '') {
  if (this.destroyed || this.saving || (moduleId && !knownModule(moduleId))) return false;
  if (this.state.mode !== 'idle') return false;
  const entrySnapshot = cloneLayout(this.layout);
  const conflicts = layoutConflicts(this.layout);
  try {
    this.carousel?.pause?.(CAROUSEL_REASON);
  } catch (error) {
    this.state = { mode: 'idle', selectedId: '', conflicts: [], guides: [] };
    this.resumeCarousel();
    this.notify('无法进入布局编辑，请重试');
    this.emitChange();
    return false;
  }
  this.entrySnapshot = entrySnapshot;
  this.gestureSnapshot = null;
  this.gesture = null;
  this.undoStack = [];
  this.state = { mode: 'editing', selectedId: moduleId, conflicts, guides: [] };
  this.editSessionActive = true;
  this.emitChange();
  return true;
}
```

- [ ] **Step 4: 创建持久锁按钮**

```js
mountLockButton() {
  const button = this.windowRef.document.createElement('button');
  button.type = 'button';
  button.className = 'hz-layout-lock';
  button.addEventListener('click', this.handleLockClick);
  this.viewport.insertBefore(button, this.stage);
  this.lockButton = button;
  this.updateLockButton();
}

handleLockClick() {
  if (this.mode() === 'idle') return this.controller.enterEdit();
  if (this.mode() === 'editing') return this.controller.saveAndExit();
  return false;
}

updateLockButton() {
  if (!this.lockButton) return;
  const saving = Boolean(this.controller?.saving);
  const unlocked = this.mode() !== 'idle';
  const state = saving ? 'saving' : unlocked ? 'unlocked' : 'locked';
  this.lockButton.dataset.layoutState = state;
  this.lockButton.disabled = saving;
  this.lockButton.setAttribute('aria-pressed', String(unlocked));
  this.lockButton.setAttribute(
    'aria-label',
    saving ? '正在保存自由布局' : unlocked ? '锁定并保存自由布局' : '解锁自由布局',
  );
  this.lockButton.title = this.lockButton.getAttribute('aria-label');
  this.lockButton.replaceChildren();
  this.renderIcon(this.lockButton, unlocked ? 'lock-open' : 'lock');
}
```

`updateLockButton()` 设置 data 状态、`aria-pressed`、`aria-label`、`title`、disabled，并用 `renderIcon` 渲染 `lock` 或 `lock-open`。
